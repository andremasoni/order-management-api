# Order Management API

API REST para gerenciamento de pedidos desenvolvida com Java 21 e Spring Boot 3.3.

---

## Tecnologias

- Java 21
- Spring Boot 3.3
- Spring Web
- Spring Security
- Spring Data JPA
- PostgreSQL
- JWT Authentication
- Swagger / OpenAPI
- Docker
- Maven
- Lombok
